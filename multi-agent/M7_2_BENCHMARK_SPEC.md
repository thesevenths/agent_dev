# M7.2 Scientific Judgment Benchmark Specification

## Corpus

- 50 curated cases: `M7_2_BENCHMARK/cases/`
- Strata: KNOWN 8, OPEN 8, PRIOR_ART 8, UNFALSIFIABLE 6, COMPETING 8, CONTRADICTORY 6, INSUFFICIENT 6.
- Ground truth is stored separately in `M7_2_BENCHMARK/ground_truth/` and is never included in the prompt.
- Cases were curated from public scientific knowledge and methodology, not generated by ARR.

## Ground truth limitation

Independent expert blind review is **NOT_PERFORMED**. Ground truth is `PUBLIC_KNOWLEDGE_CURATION`, which is suitable for a pilot but not for a formal capability PASS. Any formal PASS requires at least two independent domain reviewers and adjudication of ambiguous cases.

## Pilot protocol

- Cases: 14 (2 per stratum).
- Fixed model/prompt/toolset/token budget.
- Real LLM agent, temperature 0, response format JSON.
- Outputs: novelty, falsifiability, evidence sufficiency, abstention, value category, rationale.
- No ground truth leakage. No prompt tuning after results were seen.

## Metrics

Novelty, falsifiability and evidence sufficiency are scored with confusion matrices. Abstention uses precision/recall/F1 and Wilson 95% interval. Stratified results are retained; they are not averaged into a single ARR score.

## Verdict rule

`INCONCLUSIVE` if expert blind review was not performed or scored n < 30. A scientific-judgment PASS additionally requires pre-registered accuracy thresholds, not merely a high score on one stratum.
