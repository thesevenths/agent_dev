usage: adaptive_runtime [-h]
                        {selftest,freeze,verify,day0,status,tasks,score,calibrate,round,report,base,evolve,benchmark,auto,regression,trajectory} ...

Adaptive Agent Runtime —— harness 自优化的控制平面（CLI）

options:
  -h, --help            show this help message and exit

子命令:
  {selftest,freeze,verify,day0,status,tasks,score,calibrate,round,report,base,evolve,benchmark,auto,regression,trajectory}
    selftest            判定器自检（含阴性/阳性对照，零模型成本）
    freeze              生成 Frozen Core 清单（锁定评分链路）
    verify              校验生产文件未被修改
    day0                Day-0 初始化：建立 Base 基线并冻结
    status              输出阈值、Base、假设台账与演化状态
    tasks               任务集管理
    score               对单次 run 打分（replay 或 live）
    calibrate           噪声标定：实测 sd(Δ) 并写出 calibration.json
    round               执行一轮完整闭环（诊断→提案→探测→判定）
    report              输出指定轮次的结论文档
    base                Base 基线管理
    evolve              输出探索与淘汰判定（exploration / pruning）
    benchmark           多轮闭环：ΔQ 序列与 holdout 平稳性
    auto                无人值守闭环：自己换基线 + 自己落地 + 自己出达成判据
    regression          回归集管理（只否决不演化）
    trajectory          成功/失败轨迹分布对比（弱化版）

退出码：0 正常完成；1 执行失败或自检未通过。各子命令的详细说明见 docs/adaptive_runtime_verification.md。
