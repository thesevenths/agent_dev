## 一、已实现波动率（Realized Volatility）

### 1.1 公式

**已实现波动率**：
```
RV = sqrt( (1/N) * Σ (r_t - r̄)² )
```

其中：
- $r_t$：第 $t$ 天的收益率。
- $r̄$：平均收益率。
- $N$：天数。

### 1.2 业务意义

**公式中每个运算的业务含义**：

| 运算 | 业务含义 |
| --- | --- |
| **$r_t - r̄$** | **偏离平均的幅度**：第 $t$ 天的收益率比平均收益率高（或低）多少。 |
| **$(r_t - r̄)²$** | **偏离幅度的平方**：把偏离幅度放大，避免正负抵消（比如一天涨 2%，一天跌 2%，平均为 0，但波动很大）。 |
| **Σ** | **累加**：把所有天的偏离幅度平方加起来，得到总的波动程度。 |
| **1/N** | **平均**：把总波动程度除以天数，得到平均波动程度。 |
| **sqrt** | **开方**：把平方后的单位还原回原来的单位（比如收益率是百分比，平方后是百分比的平方，开方后回到百分比）。 |

### 1.3 数值例子

**假设**：
- 某股票过去 5 天的收益率分别为：2%, -1%, 3%, -2%, 1%。

**计算步骤**：

1. **计算平均收益率**：
   ```
   r̄ = (2% + (-1%) + 3% + (-2%) + 1%) / 5 = 3% / 5 = 0.6%
   ```

2. **计算每天的偏离幅度**：
   ```
   第 1 天：2% - 0.6% = 1.4%
   第 2 天：-1% - 0.6% = -1.6%
   第 3 天：3% - 0.6% = 2.4%
   第 4 天：-2% - 0.6% = -2.6%
   第 5 天：1% - 0.6% = 0.4%
   ```

3. **计算偏离幅度的平方**：
   ```
   第 1 天：(1.4%)² = 1.96%²
   第 2 天：(-1.6%)² = 2.56%²
   第 3 天：(2.4%)² = 5.76%²
   第 4 天：(-2.6%)² = 6.76%²
   第 5 天：(0.4%)² = 0.16%²
   ```

4. **累加偏离幅度的平方**：
   ```
   Σ = 1.96%² + 2.56%² + 5.76%² + 6.76%² + 0.16%² = 17.2%²
   ```

5. **计算平均波动程度**：
   ```
   (1/N) * Σ = (1/5) * 17.2%² = 3.44%²
   ```

6. **开方得到已实现波动率**：
   ```
   RV = sqrt(3.44%²) = 1.85%
   ```

**解释**：
- 该股票过去 5 天的已实现波动率为 1.85%，表示每天收益率平均偏离平均收益率 1.85%。
- 如果已实现波动率较高，表示股票波动较大，风险较高。
- 如果已实现波动率较低，表示股票波动较小，风险较低。

## 二、GARCH 模型

### 2.1 公式

**GARCH(1,1) 模型**：
```
σ_t² = ω + α * ε_{t-1}² + β * σ_{t-1}²
```

其中：
- $σ_t²$：第 $t$ 天的波动率平方（方差）。
- $ω$：常数项。
- $α$：ARCH 项系数。
- $ε_{t-1}²$：第 $t-1$ 天的残差平方。
- $β$：GARCH 项系数。
- $σ_{t-1}²$：第 $t-1$ 天的波动率平方（方差）。

### 2.2 业务意义

**公式中每个运算的业务含义**：

| 运算 | 业务含义 |
| --- | --- |
| **$ω$** | **基础波动率**：市场的基础波动水平，即使没有过去的波动，市场也有这个基础波动。 |
| **$α * ε_{t-1}²$** | **过去的冲击**：第 $t-1$ 天的残差平方（即过去的冲击）对今天波动率的影响。$α$ 表示过去的冲击对今天波动率的影响程度。 |
| **$β * σ_{t-1}²$** | **过去的波动率**：第 $t-1$ 天的波动率平方（即过去的波动率）对今天波动率的影响。$β$ 表示过去的波动率对今天波动率的影响程度。 |
| **$+$** | **累加**：把基础波动率、过去的冲击、过去的波动率加起来，得到今天的波动率。 |

### 2.3 数值例子

**假设**：
- $ω = 0.0001$（基础波动率）。
- $α = 0.1$（过去的冲击对今天波动率的影响程度）。
- $β = 0.85$（过去的波动率对今天波动率的影响程度）。
- 第 $t-1$ 天的残差平方 $ε_{t-1}² = 0.0004$。
- 第 $t-1$ 天的波动率平方 $σ_{t-1}² = 0.0002$。

**计算步骤**：

1. **计算基础波动率**：
   ```
   $ω = 0.0001$
   ```

2. **计算过去的冲击对今天波动率的影响**：
   ```
   $α * ε_{t-1}² = 0.1 * 0.0004 = 0.00004$
   ```

3. **计算过去的波动率对今天波动率的影响**：
   ```
   $β * σ_{t-1}² = 0.85 * 0.0002 = 0.00017$
   ```

4. **累加得到今天的波动率平方**：
   ```
   $σ_t² = 0.0001 + 0.00004 + 0.00017 = 0.00031$
   ```

5. **开方得到今天的波动率**：
   ```
   $σ_t = sqrt(0.00031) = 0.0176 = 1.76\%$
   ```

**解释**：
- 该股票今天的波动率为 1.76%，表示今天收益率的标准差为 1.76%。
- 如果 $α$ 较高，表示过去的冲击对今天波动率的影响较大，市场波动性较高。
- 如果 $β$ 较高，表示过去的波动率对今天波动率的影响较大，市场波动性具有持续性。
- 如果 $α + β$ 接近 1，表示市场波动性具有长期记忆性，即过去的波动率对今天波动率的影响较大。

## 三、隐含波动率（Implied Volatility）

### 3.1 公式

**隐含波动率**：
```
隐含波动率 = 通过期权价格反推出来的波动率
```

**Black-Scholes 公式**（用于计算期权价格）：
```
C = S * N(d1) - K * e^{-rT} * N(d2)
```

其中：
- $C$：期权价格。
- $S$：标的资产价格。
- $N(d1)$：标准正态分布的累积分布函数。
- $K$：行权价。
- $e^{-rT}$：折现因子。
- $N(d2)$：标准正态分布的累积分布函数。
- $d1 = \frac{\ln(S/K) + (r + σ²/2)T}{σ\sqrt{T}}$
- $d2 = d1 - σ\sqrt{T}$

### 3.2 业务意义

**公式中每个运算的业务含义**：

| 运算 | 业务含义 |
| --- | --- |
| **$S * N(d1)$** | **标的资产价格 * 概率**：标的资产价格乘以在到期时标的资产价格高于行权价的概率。 |
| **$K * e^{-rT} * N(d2)$** | **行权价 * 折现因子 * 概率**：行权价乘以折现因子（即行权价的现值）乘以在到期时标的资产价格高于行权价的概率。 |
| **$-$** | **相减**：标的资产价格的期望值减下行权价的现值的期望值，得到期权的理论价格。 |
| **$σ$** | **隐含波动率**：通过期权价格反推出来的波动率，表示市场对未来波动率的预期。 |

### 3.3 数值例子

**假设**：
- 标的资产价格 $S = 100$。
- 行权价 $K = 100$。
- 无风险利率 $r = 5\%$。
- 到期时间 $T = 1$ 年。
- 期权价格 $C = 10$。

**计算步骤**：

1. **假设隐含波动率 $σ = 20\%$**：
   ```
   $d1 = \frac{\ln(100/100) + (0.05 + 0.2²/2) * 1}{0.2 * \sqrt{1}} = \frac{0 + (0.05 + 0.02) * 1}{0.2} = \frac{0.07}{0.2} = 0.35$
   $d2 = 0.35 - 0.2 * \sqrt{1} = 0.35 - 0.2 = 0.15$
   ```

2. **计算 $N(d1)$ 和 $N(d2)$**：
   ```
   $N(0.35) = 0.6368$
   $N(0.15) = 0.5596$
   ```

3. **计算期权价格**：
   ```
   $C = 100 * 0.6368 - 100 * e^{-0.05 * 1} * 0.5596 = 63.68 - 100 * 0.9512 * 0.5596 = 63.68 - 53.23 = 10.45$
   ```

4. **调整隐含波动率**：
   - 如果计算出的期权价格 $C = 10.45$ 高于实际期权价格 $C = 10$，说明隐含波动率 $σ = 20\%$ 过高，需要降低隐含波动率。
   - 如果计算出的期权价格 $C = 10.45$ 低于实际期权价格 $C = 10$，说明隐含波动率 $σ = 20\%$ 过低，需要提高隐含波动率。

5. **迭代计算**：
   - 通过迭代计算，找到使计算出的期权价格等于实际期权价格的隐含波动率。
   - 假设最终找到的隐含波动率 $σ = 19\%$。

**解释**：
- 该期权的隐含波动率为 19%，表示市场对未来 1 年的波动率预期为 19%。
- 如果隐含波动率较高，表示市场预期未来波动较大，期权价格较高。
- 如果隐含波动率较低，表示市场预期未来波动较小，期权价格较低。

## 四、总结

### 4.1 三种波动率模型的对比

| 模型 | 公式 | 业务意义 | 数值例子 |
| --- | --- | --- | --- |
| **已实现波动率** | $RV = sqrt( (1/N) * Σ (r_t - r̄)² )$ | 过去一段时间内实际发生的波动率，反映市场实际波动情况。 | 某股票过去 5 天的已实现波动率为 1.85%，表示每天收益率平均偏离平均收益率 1.85%。 |
| **GARCH 模型** | $σ_t² = ω + α * ε_{t-1}² + β * σ_{t-1}²$ | 时间序列模型，用于预测波动率变化。 | 某股票今天的波动率为 1.76%，表示今天收益率的标准差为 1.76%。 |
| **隐含波动率** | 通过期权价格反推出来的波动率 | 期权价格中隐含的波动率，反映市场对未来波动率的预期。 | 某期权的隐含波动率为 19%，表示市场对未来 1 年的波动率预期为 19%。 |

### 4.2 三种波动率模型的应用场景

| 模型 | 应用场景 |
| --- | --- |
| **已实现波动率** | 用于评估过去一段时间内市场实际波动情况，帮助投资者了解市场风险。 |
| **GARCH 模型** | 用于预测未来波动率，帮助投资者制定风险管理策略。 |
| **隐含波动率** | 用于评估市场对未来波动率的预期，帮助投资者制定期权交易策略。 |

### 4.3 三种波动率模型的局限性

| 模型 | 局限性 |
| --- | --- |
| **已实现波动率** | 只能反映过去一段时间内市场实际波动情况，无法预测未来波动率。 |
| **GARCH 模型** | 执行难度高，需要大量历史数据，且模型参数估计复杂。 |
| **隐含波动率** | 执行难度高，需要期权价格数据，且模型假设（如 Black-Scholes 公式）可能不符合实际。 |
