# Step 1 — 澄清用户意图

AS_OF: 2026-10-07 21:48

## 用户原始问题
"最近一个月那个机构在卖出跑路？加息也不多啊，为啥这么敏感了？"

## 待澄清问题清单
1. **机构范围**：具体指哪家机构或哪类机构？
   - 北向资金（沪股通/深股通）？
   - 某家公募基金 / 私募基金？
   - 某家券商自营 / 保险资金？
   - 还是泛指"机构席位"（龙虎榜）？
2. **市场范围**：A股 / 港股 / 美股？
3. **"卖出跑路"的量化标准**：
   - 单月净卖出超过 X 亿元？
   - 连续 N 日净卖出？
   - 持仓占比下降超过 X 个百分点？
4. **"加息"指哪边**：
   - 国内（LPR / MLF / 逆回购利率）？
   - 海外（美联储 FOMC / 欧央行 / 日央行）？
5. **"敏感"的具体表现**：
   - 股价/指数下跌？
   - 成交量萎缩？
   - 机构持仓快速下降？
   - 还是市场情绪/舆情变化？
