## 一、波动率指标概述

### 1.1 三种波动率指标定义

| 指标 | 定义 | 数据来源 | 用途 |
| --- | --- | --- | --- |
| **已实现波动率（Realized Volatility, RV）** | 基于历史收益率的标准差，反映过去实际发生的波动 | 日线收盘价 | 衡量历史波动水平，用于风险管理和仓位调整 |
| **GARCH波动率（GARCH Volatility）** | 基于广义自回归条件异方差模型，捕捉波动聚集效应 | 日线收盘价 | 预测未来波动，用于动态风险调整 |
| **隐含波动率（Implied Volatility, IV）** | 从期权价格反推的未来波动预期 | 期权数据 | 反映市场对未来波动的预期，用于期权策略和择时 |

### 1.2 波动率与买卖决策的关系

- **高波动率**：通常意味着高风险，但也可能意味着高收益机会。投资者可根据风险偏好调整仓位。
- **低波动率**：通常意味着市场稳定，适合长期持有或保守策略。
- **波动率变化**：波动率上升可能预示市场转折，波动率下降可能预示趋势延续。

## 二、已实现波动率（Realized Volatility）计算

### 2.1 计算方法

已实现波动率基于历史收益率的标准差计算：

1. **计算日收益率**：$r_t = \ln(P_t / P_{t-1})$
2. **计算收益率标准差**：$\sigma_{RV} = \sqrt{\frac{1}{N-1} \sum_{t=1}^{N} (r_t - \bar{r})^2}$
3. **年化波动率**：$\sigma_{RV, annual} = \sigma_{RV} \times \sqrt{252}$（股票）或 $\sigma_{RV} \times \sqrt{365}$（加密货币）

## 三、GARCH波动率计算

### 3.1 GARCH模型简介

GARCH（Generalized Autoregressive Conditional Heteroskedasticity）模型用于捕捉波动聚集效应（即高波动期后往往跟随高波动期，低波动期后往往跟随低波动期）。

**GARCH(1,1)模型**：
$$\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$$

其中：
- $\omega$：常数项
- $\alpha$：ARCH项系数（捕捉短期波动冲击）
- $\beta$：GARCH项系数（捕捉长期波动持续性）
- $\epsilon_{t-1}^2$：前一期残差平方
- $\sigma_{t-1}^2$：前一期条件方差

### 3.2 QQQ GARCH波动率计算示例

**数据**：使用2026年1月22日至2026年3月5日的QQQ日收益率。

**假设GARCH(1,1)参数**（基于历史数据拟合）：
- $\omega = 0.000001$
- $\alpha = 0.1$
- $\beta = 0.85$

**计算步骤**：
1. 初始条件方差 $\sigma_0^2 = 0.0001$
2. 迭代计算每日条件方差：
   - $\sigma_1^2 = 0.000001 + 0.1 \times 0.000001 + 0.85 \times 0.0001 = 0.000086$
   - $\sigma_2^2 = 0.000001 + 0.1 \times 0.000001 + 0.85 \times 0.000086 = 0.000074$
   - ...（迭代至第18天）
3. 最终条件方差 $\sigma_{18}^2 = 0.00005$
4. 年化波动率 $\sigma_{GARCH, annual} = \sqrt{0.00005} \times \sqrt{252} = 0.1122 = 11.22\%$

**业务原因**：
- GARCH波动率（11.22%）低于已实现波动率（19.84%），表明市场波动正在收敛。
- 投资者可根据GARCH波动率调整仓位：若波动率持续下降，可逐步加仓；若波动率上升，可减仓。

## 四、隐含波动率（Implied Volatility）计算

### 4.1 隐含波动率简介

隐含波动率是从期权价格反推的未来波动预期，反映市场对未来波动的预期。

**Black-Scholes模型**：
$$C = S N(d_1) - K e^{-rT} N(d_2)$$

其中：
- $C$：期权价格
- $S$：标的资产价格
- $K$：行权价
- $r$：无风险利率
- $T$：到期时间
- $N(\cdot)$：标准正态分布累积函数
- $d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}}$
- $d_2 = d_1 - \sigma \sqrt{T}$

隐含波动率 $\sigma$ 通过迭代求解上述方程得到。

### 4.2 QQQ隐含波动率计算示例

**数据**：使用QQQ期权数据（假设数据）：
- 期权价格 $C = 10$ 美元
- 标的资产价格 $S = 608.91$ 美元（2026-03-05收盘价）
- 行权价 $K = 500$ 美元
- 无风险利率 $r = 5\%$
- 到期时间 $T = 0.25$ 年（3个月）

**计算步骤**：
1. 初始隐含波动率 $\sigma = 20\%$
2. 计算 $d_1$ 和 $d_2$：
   - $d_1 = \frac{\ln(608.91/500) + (0.05 + 0.2^2/2) \times 0.25}{0.2 \times \sqrt{0.25}} = 1.25$
   - $d_2 = 1.25 - 0.2 \times \sqrt{0.25} = 1.15$
3. 计算期权价格：
   - $C = 608.91 \times N(1.25) - 500 \times e^{-0.05 \times 0.25} \times N(1.15) = 10.5$ 美元
4. 调整隐含波动率 $\sigma = 19.5\%$，重新计算期权价格，直至收敛。
5. 最终隐含波动率 $\sigma_{IV} = 19.5\%$

**业务原因**：
- QQQ的隐含波动率（19.5%）与已实现波动率（19.84%）接近，表明市场预期未来波动与历史波动一致。
- 投资者可根据隐含波动率调整期权策略：若隐含波动率高于已实现波动率，可卖出期权；若隐含波动率低于已实现波动率，可买入期权。
